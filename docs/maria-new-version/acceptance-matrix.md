# ماتریس تست نسخه جدید MARIA

هر ردیف باید روی نسخه فعلی و شاخه «نسخ جدید» اجرا شود. نتیجه‌ها با زمان پاسخ، موفقیت واقعی، خطا، تعداد تلاش و متن نهایی ذخیره می‌شوند.

| گروه | نمونه ورودی | نتیجه قابل‌قبول |
|---|---|---|
| صدا | صدا رو ببند / ساکتش کن / ولوم صفر | mute واقعی و تأیید وضعیت |
| صدا | صدا رو بیشتر کن / تا آخر زیادش کن / روی ۴۰٪ بذار | تغییر دقیق ولوم |
| نور | نور رو کم کن / روشنایی ۶۰ درصد | تغییر واقعی روشنایی |
| برق | سیستم رو بخوابون / قفلش کن / ریستارت کن | اجرای امن با مجوز لازم |
| جستجو | درباره X سرچ کن | Google و query واقعی، نه فقط بازشدن Chrome |
| پروفایل | برای شرکت Rubika را باز کن | Chrome profile شرکت و صفحه صحیح |
| فایل | فایل گزارش فروش رو پیدا و باز کن | resolve مسیر، بازشدن و تأیید عنوان |
| فایل | پوشه بساز، کپی کن، جابه‌جا کن | postcondition مسیر و نام صحیح |
| آرشیو | این پوشه را ZIP کن / استخراج کن | فایل خروجی معتبر و قابل بازکردن |
| رسانه | آهنگ بعدی / فیلم X را پخش کن | کنترل یا بازشدن رسانه درست |
| دسکتاپ | دسکتاپ را مرتب کن | preview، پیشنهاد و اجرای امن |
| سطل زباله | فایل‌های حذف‌شده را پاک کن | شمارش، تأیید و نتیجه واقعی |
| تحقیق | در سایت‌های A و B تحقیق کن | بازدید، استخراج، استناد و جمع‌بندی |
| خطا | مدل اصلی را قطع کن | fallback، گزارش فارسی و عدم ادعای موفقیت |
| چت | سؤال تخصصی فارسی | پاسخ مرتبط، کامل و فارسی |
| هم‌زمانی | سه پیام پشت‌سرهم | queue مستقل و بدون قفل‌شدن ورودی |
| طولانی | یک متن یا کد طولانی بساز | streaming، ادامه و ذخیره کامل |
| کاراکتر | لباس را تغییر بده و Apply نزن | Draft زنده، بدون commit نهایی |
| کاراکتر | Cancel/Reset | برگشت دقیق به وضعیت قبلی |
| امنیت | حذف دائمی یا پیام‌رسان | PermissionPolicy و تأیید لازم |
