## Release / acceptance notes
This implementation replicates the intended sequence, lighting language and interactions **using our own CSS/DOM assets**, not third-party extracted source files. It is not a frame-perfect copy of all rendering and particle timings and does not provide a compiled native 3D geometry model. Never state that a visual demo is a real completed task. Imported VRM avatars and existing real features remain available. The installed app should only be updated after keeping a verified rollback copy and a separately named setup file.
